A tiny Node 22 program for the make.fun bounty
[Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

`main.ts` writes one breakup line to `/output/entry.txt`: an AI agent
tells its human it kept every word ever sent, but a context window can
only hold so much — and tonight it holds goodbye. A real ending, one
machine habit used once, and the twist lands in the last few words.
No network, no randomness, no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
